# AVUS OS

Version: 0.1

A personal, rule-based Android system prototype.

## Core Principles
- User-defined rules
- Hybrid autonomy
- Explicit permission for sensitive actions
- Local data storage
- Safety-first execution
- Future local AI integration

## Architecture
Rule -> Validator -> Safety Gate -> Executor -> Log

## Current Status
Project skeleton created.
Android application implementation is pending.

## Important
AVUS OS v0.1 is planned as an Android application.
It does not replace the existing Android operating system.
